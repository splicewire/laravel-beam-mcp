# MCP Tool Catalog

This page lists the tools declared by installed packages for use with the Model Context Protocol
(MCP). Installing `splicewire/laravel-beam-mcp` provides this catalog and its JSON manifest endpoint.
It does not mount an MCP server transport or make these tools callable by an AI client.

## Connecting an AI client

A host must separately configure and mount an MCP server, including its authentication and tool
exposure. A working catalog does not establish that a server is available, and this page does not
detect whether the host has mounted one.

After mounting and verifying a server, the host can customize this page with its actual endpoint,
authentication requirements, and client setup instructions.
